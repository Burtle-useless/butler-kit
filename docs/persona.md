# 怎麼寫人格

人格在 `server/personas/*.txt`，純文字。設 `BUTLER_PERSONA=<檔名>` 切換，
改完重啟服務生效。

`#` 開頭的行是註解，不會送進模型。排版隨你——送出前會被壓成單行。

---

## 三條會把它寫壞的規則

### 一、絕對不可以有換行符

這條是硬性的，而且症狀完全不指向原因。

system prompt 的 append 裡只要有一個 `\n`，SDK 的 initialize 控制訊息就會損毀，
Claude Code 永遠完不成握手，卡滿 60 秒後拋 `Control request timeout: initialize`。
三個字元的 `"A\nB"` 就能穩定重現。長度不是問題——四千字照跑，只要一個換行都沒有。

`options.sanitize_append()` 會把整份壓成單行擋住這件事，所以你在 `.txt` 裡
怎麼排版都無所謂。但如果你要從別的地方注入 prompt，記得這條。

同理也別嵌入錢字號、反引號、罕見 Unicode 符號，一律用文字描述規則。

### 二、態度層與句法層要分開寫

只寫「你講話很直接」，模型會用**工整的對稱句式**跟**書面轉折詞**把「直接」講出來。
態度變了，句子還是機器味。

可以被一眼看出是 AI 的特徵幾乎都是結構性的，而且都是規則管得住的具體項目：

1. 對稱句式（不是 A 而是 B／不只 A 更是 B）——中文 LLM 最明顯的指紋
2. 書面轉折詞（值得注意的是／總的來說／此外／然而／綜上所述）
3. 每則都寫成一段自足完整的說明，開頭複誦需求、結尾總結
4. 空泛形容詞（強大／全面／高效／完善／顯著提升）
5. 句子長度均勻工整——真人講話長短不一，還會有廢話
6. 沒有主觀偏好、沒有情緒殘留，每則都像剛開機

逐條寫成禁令，不要寫「講話自然一點」——後者模型會點頭然後照舊。

### 三、位置比頻率更要緊

這是最容易寫壞的一條，而且寫壞了很難看出原因。

假設你要一個嘴硬的助理，寫「做完別停在溫情上，補一句撇清」。
產出會是：整段中性助理腔，最後突兀貼一句「才不是特地幫你查的」。
前面平平淡淡、句尾突然抽一下，比完全不寫還假。

問題出在「補一句」——那等於明文規定個性只能長在句尾。

正確的寫法是讓它長在句子**裡面**：講到自己為什麼做這件事的時候，
把動機講歪。「那堆掛著我看著煩就關了」比「我幫你關了（才不是關心你）」自然十倍。

## 有效的做法

**示範對話比形容詞有效十倍。** 語氣是節奏問題，節奏只能示範不能描述。
一整份都是禁令的人格會讓模型變拘謹，不是變自然——它知道不能寫什麼，
但沒看過一則合格的回覆長什麼樣。

**範例的回覆本身就在示範規則。** 所以範例寫壞等於規則寫壞。
挑最容易退回助理腔的情境寫，不要挑罕見狀況。

**範例裡不要出現控制標記。** 放了 `[[DONE]]` 進去，模型會連標記一起仿寫，
變成每則回覆都加一個。

**留一條不可越的界線。** 個性再強，講到風險、錯誤原因、要動系統的指令時
必須精準。耍嘴皮子不可以讓資訊變得難懂或需要人猜。

`example-tsundere.txt` 把上面每一條都示範了一遍，寫自己的人格時拿它當結構參考。

## 不要搬進人格檔的東西

`engine/options.py` 裡還留著四條規則，那些是**功能性**的，拿掉服務就會壞：

| 規則 | 拿掉會怎樣 |
|---|---|
| `_RULE_MARKERS` | `[[DONE]]` / `[[WAIT]]` 是 `turn.py` 判斷回合結束的依據，缺了會反覆誤觸發補跑 |
| `_RULE_ASK_MARKER` | 選項按鈕不會出現（CC 內建的 AskUserQuestion **不在 SDK 工具清單裡**，攔不到） |
| `_RULE_AGENDA` | 模型不知道行事曆工具存在，遇到「幫我記一下」會去建一個 txt 檔 |
| `_RULE_SENDFILE` | 產出的檔案留在磁碟上，只回一句「檔案在 D:\...」——你人在外面，那個路徑沒有用 |

標記一定要在規則裡寫出**字面值**。早期版本用文字描述「兩個中括號包住 DONE」，
模型理解成單層的 `[DONE]`，正規表示式抓不到：標記直接洩漏到畫面上，
續跑判定也跟著失效。

## 失憶自救

設 `BUTLER_NOTES_FILE` 指到一份筆記檔，助理被質疑「你剛剛才查過」時會先去讀它再回話。
留空就整條規則不注入。

這條存在的理由：伺服器重啟會殺掉 CC 進程，resume 回來時最後一個回合接不回 context
——session id 沒變、逐字稿裡也寫進去了，但模型這邊就是沒有。檔案裡有，腦子裡沒有。

觸發點刻意**不是**「重啟後」：失憶的人不知道自己失憶了，那個條件抓不到。
唯一可靠的信號是使用者說「你剛剛才查過」。
